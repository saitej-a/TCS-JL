# Plan 12-01 — Stitch-Designs Screen Reconciliation

**Goal (backward):** after this plan, every one of the 45 screen compositions in
`frontend/stitch designs/` maps to rebuilt, tested, honest-data UI in `frontend/src/`, with
the mapping recorded in `RECONCILIATION.md` and zero v1 artifacts anywhere in the rebuilt
markup.

## Global conventions (binding on every task)

- **G-1 (D-01):** structure from the composition's `code.html`; appearance repainted through
  v2 vocabulary only — `brand-*` (sky), `TYPOGRAPHY`/`SURFACES` from `@/theme/tokens`, the
  repo's radii/shadow scale. Never `indigo-*`, never `font-Inter`/Inter imports, never
  `material-symbols`, never the composition's CDN `<script>` Tailwind config.
- **G-2:** every rebuilt file passes `grep -nE "indigo|Inter|material-symbols"` with zero
  hits (the string "Inter" must not appear even in comments; use "the compositions' display
  font" phrasing if a comment needs one).
- **G-3:** mock fiction never ships — check each screen's copy against
  `09.5 VERIFICATION.md §3` and `09.5.1-CONTEXT.md §3.3` before rebuilding; keep the shipped
  honest copy/state, adopt the composition's layout. Cite the ledger row in the
  RECONCILIATION.md entry.
- **G-4 (D-05):** icons come from `lucide-react` named imports, replacing each composition's
  `data-icon="name"` glyph (e.g. `track_changes`→`Target`, `privacy_tip`→`ShieldCheck`,
  `mark_email_read`→`MailCheck`). Record each non-obvious mapping in the RECONCILIATION row.
- **G-5:** a rebuilt screen's test suite is updated in the same task and pins the new DOM;
  no task ends with a suite still asserting the old structure.
- **G-6 (D-06):** local markup first; extract a shared component only when the identical
  pattern (same markup shape + same props) has appeared in ≥3 rebuilt screens — record any
  extraction in the RECONCILIATION entry.
- **G-7 (D-04):** landing and privacy keep 9.5.1's awaiting-copy states and honesty rules;
  the legal content modules' data-driven shape survives.
- **G-8:** modal content renders inside `frontend/src/components/Modal.tsx` (existing §6.6
  mechanics: focus trap, Escape/backdrop dismiss, bottom-sheet <640px). Never re-implement
  modal mechanics.

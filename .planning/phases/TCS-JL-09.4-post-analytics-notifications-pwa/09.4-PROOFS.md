## Reconciliation notes (deliberate divergences from the mockups)

1. **§7.10 row text**: the mockup shows one sentence per row; the API ships
   `title` (headline) + `message` (body). The row renders the headline primary
   and the message as the quoted snippet — no field invented, preview
   affordance preserved.
2. **§7.9 wait times**: rows say "Offer letter to joining letter" / "Survey to
   joining letter" (the payload's two baselines). The mockup's single-row
   presentation assumes data that 7.2 suppresses; suppression copy is shown
   per-metric instead of fabricated numbers.
3. **§7.9 KPI digits**: mockup's `1,248 / 412 / 320 / 85` are placeholder
   fiction; live values render from `/analytics/overview/`.
4. **§7.10 unread marker**: mockup shows `(●) UNREAD` with a count bubble; the
   spec's copy table fixes `● UNREAD` / `○ READ` — spec wins.
5. **Bell on public routes**: rendered for visitors without a badge, linking to
   `/login?next=%2Fnotifications` (plan: "hidden on public routes" reads as no
   unread lie, not a missing affordance).
6. **Locked-post banner** verified live: composer replaced by the amber 🔒
   banner, existing comments still visible (`/community/posts/6b060b4f…`).

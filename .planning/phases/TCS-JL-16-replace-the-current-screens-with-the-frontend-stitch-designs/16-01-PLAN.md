<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Browser → Backend Auth API | Unauthenticated credentials, registration inputs, password reset requests, and verification tokens cross here. |
| URL Parameters → Password Reset & Verification Handlers | Reset tokens and verification tokens passed via query parameters or path segments. |
| User Browser → Onboarding State Machine | Candidate profile attributes and milestone status transitions submitted during onboarding. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Spoofing / Tampering | Login & Register Forms (`LoginPage.tsx`, `RegisterPage.tsx`) | mitigate | Enforce client-side sanitization and validation matching backend `passwordRules.ts`; maintain 401/429 rate-limiting countdowns without exposing backend internals. |
| T-16-02 | Information Disclosure | Forgot & Reset Password (`ForgotPasswordPage.tsx`, `ResetPasswordPage.tsx`) | mitigate | Preserve anti-enumeration uniform responses regardless of email existence; render attempted tokens in wrapping-safe elements to prevent DOM injection. |
| T-16-03 | Elevation of Privilege / Tampering | Onboarding Wizard (`OnboardingPage.tsx`) | mitigate | Guard wizard progression with server-validated `profile_completed` state; walk-the-chain timeline event creation ensures valid status transition history. |
| T-16-SC | Tampering | Vendored Fonts & Static Assets | mitigate | Use vendored WOFF2 font files in `frontend/public/fonts/`; strictly forbid runtime script injection or external CDN references (`cdn.tailwindcss.com`, `fonts.googleapis.com`). |
</threat_model>

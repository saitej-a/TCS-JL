<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Browser → Timeline Event Mutation Endpoints | Candidate creates, updates, or deletes recruitment milestone events via POST/PATCH/DELETE. |
| Dashboard Data Feed → Browser Presentation | Aggregated community metrics and benchmark cohorts cross from backend to client view. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-06 | Information Disclosure | Candidate Dashboard (`DashboardPage.tsx`) | mitigate | Enforce privacy suppression: when benchmark cohort candidate count is below 5, redact wait-time percentiles and render server-provided privacy notice. |
| T-16-07 | Tampering / IDOR | Recruitment Timeline (`TimelinePage.tsx`, `TimelineEventModal.tsx`) | mitigate | Ensure timeline mutation operations strictly target the authenticated candidate's timeline events; validate milestone status against allowed state machine transitions. |
| T-16-SC | Tampering | Vendored Static Assets | mitigate | Icons rendered purely from vendored Material Symbols Outlined font; zero external network requests for stylesheets or icons. |
</threat_model>

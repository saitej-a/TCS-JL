<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Browser → Account Mutation & Deletion Endpoints | Password changes, identity privacy mode updates, and irreversible account purge requests cross here. |
| Staff Browser → Admin Moderation & Broadcast Endpoints | Content moderation actions, candidate ban decisions, and site-wide announcement publications cross here. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-10 | Repudiation / Tampering | Account Deletion (`SettingsDangerPage.tsx`) | mitigate | Require explicit 3-factor confirmation: typed "DELETE", acknowledgement checkbox, and valid current password; immediately revoke session tokens upon completion. |
| T-16-11 | Elevation of Privilege | Admin Moderation & Announcements (`AdminReportsPage.tsx`, `AdminAnnouncementsPage.tsx`) | mitigate | Guard routes client-side with `RequireStaff`; enforce backend staff permission checks; require explicit confirmation modal before publishing live broadcasts. |
| T-16-SC | Tampering | Vendored Static Assets | mitigate | Icons rendered purely from vendored Material Symbols Outlined font; zero external script dependencies. |
</threat_model>
